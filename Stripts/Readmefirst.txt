    2. 对话与旁白

  说话人: 对话内容
  说话人：对话内容        ← 全角冒号同样有效
  这是旁白文字            ← 无冒号 → 旁白，不显示姓名框
  ：这是旁白              ← 全角冒号开头也是旁白
  我：xxx      <- 这里的“我”会自动替换为玩家名称

  ┌──────────────────────────────────┬────────────────────────────┐
  │               规则               │            说明            │
  ├──────────────────────────────────┼────────────────────────────┤
  │ 冒号前 ≤15 字符                  │ 识别为说话人姓名           │
  ├──────────────────────────────────┼────────────────────────────┤
  │ 全角 ： 和半角 :                 │ 通用                       │
  ├──────────────────────────────────┼────────────────────────────┤
  │ ??? 旁白 系统 narrator system    │ 不显示立绘                 │
  │ none                             │                            │
  ├──────────────────────────────────┼────────────────────────────┤
  │ player 或 我                     │ 替换为玩家输入的姓名       │
  ├──────────────────────────────────┼────────────────────────────┤
  │ 旁白出现                         │ 自动清除当前立绘           │
  ├──────────────────────────────────┼────────────────────────────┤
  │ 新说话人                         │ 自动显示对应立绘（如存在） │
  └──────────────────────────────────┴────────────────────────────┘

    3. 行内富文本

  处理顺序：*...* → ==...== → [em] → [ann]

  ┌──────────────────────┬─────────────────┬──────────────────────┐
  │         格式         │      渲染       │         字体         │
  ├──────────────────────┼─────────────────┼──────────────────────┤
  │ *文本*               │ 斜体            │ simfang（中）/       │
  │                      │                 │ timesi（英）         │
  ├──────────────────────┼─────────────────┼──────────────────────┤
  │ ==文本(注释)==       │ <u>文本</u> +   │ 正文悬浮显示注释     │
  │                      │ 悬浮提示        │                      │
  ├──────────────────────┼─────────────────┼──────────────────────┤
  │ ==文本（注释）==     │ 同上            │ 全角括号同样有效     │
  ├──────────────────────┼─────────────────┼──────────────────────┤
  │ [em]文本[/em]        │ 斜体            │ 旧格式，兼容保留     │
  ├──────────────────────┼─────────────────┼──────────────────────┤
  │ [ann=注释]文本[/ann] │ <u>文本</u> +   │ 旧格式，兼容保留     │
  │                      │ 悬浮提示        │                      │
  └──────────────────────┴─────────────────┴──────────────────────┘

  ▎ 注释括号内的文字不出现在正文中，仅鼠标悬浮时以 tooltip 浮窗显示。

    5. 资源路径规则

  5.1 三种写法

  ┌────────┬────────────────────────────────┬────────────────────┐
  │  写法  │              示例              │        行为        │
  ├────────┼────────────────────────────────┼────────────────────┤
  │ 完整路 │ /Assets/backgrounds/scenes/Nig │ 直通               │
  │ 径     │ ht.jpg                         │                    │
  ├────────┼────────────────────────────────┼────────────────────┤
  │ 带扩展 │ Night.jpg                      │ 精确匹配（大小写敏 │
  │ 名     │                                │ 感）               │
  ├────────┼────────────────────────────────┼────────────────────┤
  │ 带路径 │ scenes/Night.jpg               │ 精确匹配（大小写敏 │
  │        │                                │ 感）               │
  ├────────┼────────────────────────────────┼────────────────────┤
  │ 缺省表 │ Night                          │ 精确 → 模糊（大小  │
  │ 示     │                                │ 写不敏感）         │
  └────────┴────────────────────────────────┴────────────────────┘

  5.2 模糊匹配规则

  仅对「无扩展名 + 无路径分隔符」的裸名生效：

  - 大小写不敏感：night = NIGHT = Night
  - 分隔符等价：LinZixin_Happy = linzixin-happy = LINZIXIN HAPPY =
    linzixinhappy

  5.3 搜索目录

    6. 选项系统

  6.1 基础格式

  ? 你要怎么做？

  > 选项文字 -> 目标
  > 选项文字               ← 无目标 → 默认 _continue

  ? 支持半角 ? 和全角 ？。

  6.2 目标格式

  ┌────────────┬───────────────────────────────────┐
  │    目标    │               行为                │
  ├────────────┼───────────────────────────────────┤
  │ chapter1   │ 跳转到 chapter1 开头              │
  ├────────────┼───────────────────────────────────┤
  │ chapter1@0 │ 同上（@N 被忽略，始终从开头开始） │
  ├────────────┼───────────────────────────────────┤
  │ 5          │ 跳转到当前剧情开头                │
  ├────────────┼───────────────────────────────────┤
  │ _continue  │ 继续下一句，不跳转                │
  ├────────────┼───────────────────────────────────┤
  │ （无目标） │ 默认 _continue                    │
  └────────────┴───────────────────────────────────┘

  6.3 反应块

  > 选项文字
  > （
  >  @ch(LinZixin_Happy)
  >  林子欣：好耶！我就知道你会陪我。
  > ）

  - 括号支持全角 （） 和半角 ()
  - 括号内支持 @ 命令和对话（不支持嵌套选项）
  - 选择后先播放反应块内容，再继续后续剧情

  6.4 完整示例

  ? 你打算怎么做？

  > 陪着林子欣
  > （
  > @ch(LinZixin_smile)
  > 林子欣：好耶！我就知道你会陪我。
  > ）

  > 不陪林子欣
  > （
  > @ch(LinZixin_sad)
  > 林子欣：好吧，那你忙自己事情吧。
  > ）

  > 先想想 -> _continue

  > 不干了 -> title

  旁白：两个人一起走向了教学楼。
