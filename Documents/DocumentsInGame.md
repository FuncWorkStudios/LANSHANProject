# 特定mRNA顺式作用元件与海马CA3-CA1突触连接模式之间的对应规律

**作者：王者超**  
**指导教师：李维中**  
**单位：辰州大学生物学院 分子生物学研究室**

**辰州 071000**

## 摘要

**目的** 探讨树突局部mRNA对突触连接的选择性调控，寻找mRNA序列特征与突触连接变化之间的对应规律。  
**方法** 采用微流控分隔培养大鼠海马CA3-CA1神经元，通过光解笼mRNA递送和双光子电生理记录，筛选47种树突定位mRNA。  
**结果** 12种mRNA可稳定改变突触连接强度或形态；其效应由3′UTR上的“突触连接响应元件”（synaptic connectivity response element, SCRE）决定，核心六核苷酸基序不同，可使突触连接分别表现为增强、新生或消除。按特定时序组合给予mRNA，可重复地将同一突触群的连接矩阵从初始状态转变为目标状态，预测准确率为87.4%。  
**结论** mRNA序列中存在与突触连接模式相对应的“连接密码”，其组合与时序决定突触连接的建立、强化和消除。

**关键词**：mRNA；突触连接；树突棘；局部翻译；顺式作用元件；连接密码

---

## 1 引言

神经突触连接的特异性如何形成、维持和改变，是神经科学的核心问题之一。已有证据表明，树突中存在的mRNA可在局部被翻译，参与突触可塑性调节，但mRNA种类与具体突触连接变化之间的对应关系仍不明确。本实验筛选并验证了若干候选mRNA，分析其序列特征与突触连接变化之间的规律。

## 2 材料与方法

### 2.1 实验材料

采用出生后0 d SD大鼠海马CA3-CA1共培养体系。培养至第14天，选择形态完整、连接清晰的神经元用于实验。

### 2.2 mRNA筛选与递送

从海马组织提取树突定位mRNA，构建47种候选分子。利用微流控装置将神经元胞体与树突分隔，通过光解笼核苷酸技术在单个树突棘附近局部释放目标mRNA。每种mRNA至少在15个独立培养皿中重复。

### 2.3 突触连接测量

用双光子激光共聚焦成像记录树突棘体积变化；用膜片钳记录微型兴奋性突触后电流（mEPSC）。定义突触连接系数：

\[
SCI = \frac{\Delta 棘体积}{基线棘体积} \times \frac{\Delta mEPSC幅度}{基线mEPSC幅度}
\]

### 2.4 序列分析

对47种mRNA的3′UTR进行基序搜索，重点分析含G四链体、AU富集元件和特定六核苷酸基序的分布。

## 3 结果

### 3.1 mRNA筛选

47种候选mRNA中，12种能显著改变SCI，按效应分为三类：  
**增强型**：NSP-4、ARC、PSD-7、EIF-5、SHANK-3；  
**新生型**：SYN-12、MAP-2；  
**消除型**：MCP-1、GAP-3；  
**双向型**：BDNF-AS、CBLN-2。

### 3.2 关键基序

3′UTR中6 nt序列决定效应方向，代表性结果见表1。

**表1 部分可重复改变突触连接模式的mRNA及特征**

| 实验室编号 |       来源基因       | 3′UTR核心基序（5′–3′） |          突触效应           | 作用时程 |
| :--------: | :------------------: | :--------------------: | :-------------------------: | :------: |
|   NSP-4    |    神经突触蛋白4     |        GUCAGCC         | 棘头增大，AMPA电流增加32.6% |  30 min  |
|   SYN-12   |       突触素12       |         AUGCGU         |          新棘生成           |  45 min  |
|    ARC     | 活性调节细胞骨架蛋白 |         UGUGA          |         棘体积增大          |  60 min  |
|   PSD-7    |   突触后致密蛋白7    |         GGACU          |      突触后致密区增厚       |  90 min  |
|   MCP-1    |    微管相关蛋白1     |         CCGUAA         |      棘收缩，连接消除       |  50 min  |

### 3.3 时序组合规律

先给予SYN-12，45 min后给予PSD-7，90 min后给予NSP-4，可使SCI上升0.41±0.05，新突触稳定存在超过12 h。若先给予MCP-1再给予NSP-4，SCI回升仅0.08±0.03。结果显示，时序组合决定最终连接状态，而非单一种类mRNA的简单叠加。

## 4 讨论

本研究表明，特定mRNA通过其3′UTR中的SCRE被运输至特定突触，局部翻译后改变突触后致密区的分子组成，从而调节连接强度。更值得注意的是，不同mRNA组合的时序模式可决定突触连接矩阵的终态。这提示神经系统中可能存在基于mRNA序列与时序的“连接密码”。该规律在体外海马体系得到验证，但是否适用于其他脑区，仍需进一步研究。

# 生物分子计算机与四进制计算：  
## 基于DNA四态编码的并行运算体系  

**E. Voss，L. Shen，J. Okafor，R. Marchetti**  
赫尔墨斯生物计算研究所 第7实验室  

---

## 摘要

传统电子计算以二进制为底层逻辑，受制于冯·诺依曼瓶颈与硅基元件的物理极限。本文提出并实现了一种基于脱氧核糖核酸四碱基态的四进制分子计算架构。该体系利用DNA发夹结构的四种可区分构象，将腺嘌呤（A）、胞嘧啶（C）、鸟嘌呤（G）、胸腺嘧啶（T）映射为四进制数字0、1、2、3。通过立足点介导的链置换反应与限制性内切酶级联切割，构建了四值半加器与多位进位链。实验表明，该体系可在单管中并行完成四进制加法运算，在约$2.3×10^{12}$个分子单元中实现错误率低于$3.2×10^{-24}$。本研究为高密度生物存储、分子密码学及非二进制生命计算提供了新的技术路径。

**关键词**：生物分子计算；四进制逻辑；DNA链置换；四态编码；分子密码学

---

## 1 引言

自Adleman提出DNA计算范式以来，分子计算多将DNA视为二进制信息的载体，以双链互补状态表示0与1。然而，DNA本身具有四种天然碱基，其信息容量未被充分利用。若以单一碱基作为基本符号，DNA分子可在相同链长下提供两倍于二进制的信息密度。

本文提出一种“碱基即数字”的四进制编码策略：A=0，C=1，G=2，T=3。基于此，我们设计了四态发夹逻辑单元，通过链置换反应实现四值逻辑运算，并进一步构建了四进制半加器与多位加法器。该体系不依赖外部电子设备，所有运算均由分子识别与酶促反应自主完成。

## 2 材料与方法

### 2.1 四进制编码单元

每个四进制数字由一个12 nt的“数字域”表示。数字域的核心为单碱基差异位，位于发夹环区第3位。编码规则如下：

| 四进制数字 | 核心碱基 | 发夹环识别域（5′→3′） |
| :--------: | :------: | :-------------------: |
|     0      |    A     |     5′-AAC TTG-3′     |
|     1      |    C     |     5′-ACC TTG-3′     |
|     2      |    G     |     5′-AGC TTG-3′     |
|     3      |    T     |     5′-ATC TTG-3′     |

该差异位通过锁核酸修饰以降低错配率。发夹茎部为8 bp，包含立足点域与输出域。

### 2.2 四值半加器设计

四进制半加器由状态发夹 $H_0–H_3$ 与进位发夹H_c组成。输入链I_x首先与H_x的立足点域结合，通过分支迁移打开发夹，释放输出链O_x。输出链随后与第二输入对应发夹H_y结合，生成代表“本位和”的复合物。

四进制半加器逻辑定义如下：

\[
S = (X + Y) \bmod 4
\]

\[
C = \lfloor (X + Y) / 4 \rfloor
\]

当 $X+Y\geq4$ 时，进位发夹H_c被打开，释放进位链C_out，传递至下一数位。

### 2.3 多位进位链

多位四进制加法通过级联进位模块实现。每个数位模块包含三个功能区：输入寄存器、进位接收域和进位发出域。限制性内切酶QspI在识别到正确的四态复合物后，于特定位点切割，释放下一数位的进位链。反应在37 °C下进行，缓冲液含25 mM Tris-HCl、100 mM NaCl、10 mM MgCl₂，pH 7.5。

### 2.4 数据读出

输出链末端标记四种荧光报告子：FAM（0）、Cy3（1）、Texas Red（2）、Cy5（3）。通过共聚焦荧光显微镜或凝胶电泳分离后读取各数位信号。

## 3 结果

### 3.1 四进制半加器真值表

实验测得半加器输入输出关系如下：

|  X   |  Y   | S（本位和） | C（进位） |
| :--: | :--: | :---------: | :-------: |
|  0   |  0   |      0      |     0     |
|  0   |  1   |      1      |     0     |
|  0   |  2   |      2      |     0     |
|  0   |  3   |      3      |     0     |
|  1   |  0   |      1      |     0     |
|  1   |  1   |      2      |     0     |
|  1   |  2   |      3      |     0     |
|  1   |  3   |      0      |     1     |
|  2   |  0   |      2      |     0     |
|  2   |  1   |      3      |     0     |
|  2   |  2   |      0      |     1     |
|  2   |  3   |      1      |     1     |
|  3   |  0   |      3      |     0     |
|  3   |  1   |      0      |     1     |
|  3   |  2   |      1      |     1     |
|  3   |  3   |      2      |     1     |

荧光信噪比均高于20 dB，未观察到显著串扰。

### 3.2 多位加法验证

以四进制数 $23_4$ 与 $11_4$ 进行加法验证。计算预期为：

\[
23_4 + 11_4 = 100_4
\]

实验结果显示，个位输出为0，四位输出为0，八位输出为1。对应荧光通道中，Cy5通道（1）出现强信号，FAM与Cy3通道（0）无显著信号，证实输出为100₄。整管反应在35分钟内完成，参与计算的分子单元约$2.3×10^{12}$个。

### 3.3 错误率分析

在10⁶次并行重复中，错误率约为 $3.2×10^{-4}$。错误主要来源于G-T错配与局部二级结构导致的酶切不完全。

## 4 讨论

本体系证明DNA四碱基态可直接用于非二进制计算。与二进制DNA逻辑门相比，四进制编码使单位链长的信息密度提升一倍，并减少了多位运算所需的分子种类。四态发夹结构在热力学上可区分，且链置换反应具有良好的正交性。

错误率可通过引入更强错配区分能力的锁核酸或提高反应温度进一步降低。未来可扩展至四进制存储、四进制加密以及基于四态分子状态的有限状态机。

值得指出的是，四进制分子逻辑与遗传密码的天然四字符结构存在潜在对应关系。若将计算输出与翻译过程偶联，或可构建能够“计算并执行”的合成生物系统。

## 5 结论

本文成功构建了基于DNA四态编码的四进制生物分子计算机，实现了四值半加器与多位进位链，并验证了$23_4+11_4=100_4$的分子运算过程。该架构为分子级高密度计算与生物密码系统提供了新基础。
